# Vapor Learning Guides

Base de connaissances open source pour apprendre **Vapor**, le framework Swift côté serveur.

## Contenu

### Projets de démonstration (vidéos YouTube)

| Dossier | Chapitre |
|---------|----------|
| `1 - installation` | Création d'un projet Vapor |
| `2 - Controller et router` | Routes et Controllers |
| `3 - BDD` | Fluent et PostgreSQL |
| `4 - Middleware` | CORS, Logging, Errors |
| `5 - Authen` | Authentification JWT |
| `6 - API Advanced` | Pagination, filtres, relations |
| `7 - Mise en production` | Docker, CI/CD |

### Guides de bonnes pratiques (`/guides`)

8 guides complets rédigés pour servir de base de connaissances :

- Installation et configuration
- Controllers & Routes
- Base de données (Fluent/PostgreSQL)
- Middleware (CORS, Auth, Errors)
- Authentification JWT
- API avancée (pagination, filtres, relations)
- Déploiement production (Docker, CI/CD)
- Preview Vapor 5
